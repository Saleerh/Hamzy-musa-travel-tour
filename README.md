# Hamzy Musa Travel & Tours — Version 4: Prism Glass

A lightweight static website prototype with a premium glassmorphism design system, navy / electric blue / champagne gold / aqua palette, responsive layouts, custom SVG branding, trip enquiry builder, and a local-only admin dashboard demo.

## Preview
- Open `index.html` in a modern browser.
- Open `admin.html` to explore the local demo dashboard.

## Files
- `index.html` — marketing website and travel enquiry form
- `styles.css` — responsive visual system and V5 — Aurora Luxe glassmorphism cards
- `script.js` — navigation, enquiry builder, WhatsApp flow, and local request demo
- `admin.html`, `admin.css`, `admin.js` — local admin dashboard prototype

## Deployment
Upload the folder to any static host such as Netlify or Vercel. No build step is required.

## Important limitations
This is a front-end prototype. Booking requests stored by the demo dashboard use the browser's local storage and do not sync between devices. WhatsApp enquiries require the customer to review and send the prepared message. There is no live flight inventory, payment processing, secure administrator authentication, or central database. Before collecting real customer data, connect a secure backend, database, and authentication system. Never request or store passport details or payment-card data in this demo.


## V5 visual update
Aurora Luxe adds a refined glass-card layer, deeper translucent surfaces, soft gold edge highlights, elevated hover states, dotted atmospheric hero texture, and stronger focus accessibility. The site remains static; live booking, payment, and shared server-side request storage are not included.
